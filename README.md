# kb_real_estate

KB 주간시계열(아파트 매매·전세 가격지수) XLSX를 올리면 **전국 197개 지역**의 13·26·52주 뒤 가격지수를 예측하는 Streamlit 앱입니다.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py      # 파일을 업로드하면 최초 1회 예측 엔진을 학습·검증합니다 (약 2~3분, 이후 캐시)
pytest                              # 누수·정합성 테스트
python scripts/validate.py 20260824_주간시계열.xlsx   # walk-forward 검증 재현
```

## 어떻게 예측하나

| 구성 | 내용 |
|---|---|
| 데이터 | 매매/전세 지수 197개 지역 + KB 심리지표 4종(매수우위·매매거래활발·전세수급·전세거래활발) |
| 학습 | **전국 패널 풀링** — 지역마다 따로 학습하지 않고 모든 지역을 하나의 모델로 학습 |
| 타깃 | h주 뒤 누적 로그수익률을 직접 예측 (재귀 예측 없음), 앵커 기간 4·8·13·20·26·39·52주 사이는 보간 |
| 모델 | Ridge(강한 shrinkage) + HistGradientBoosting 평균 블렌드 |
| 피처 | 자체 모멘텀·변동성, KB 심리지표(수준·변화량·z-score·상위 시도 대비 괴리), 상위 권역 대비 상대강도 |
| 구간 | walk-forward 잔차 기반 online conformal, 변동성으로 정규화 (명목 80%) |

앱은 예측 외에 정보군별 기여도 분해, 지역 순위, 기술지표 신호(기존 기능 유지)를 제공합니다. 매매지수와 전세지수를 같은 엔진으로 예측합니다.

## 검증 방법 (숫자를 믿기 위한 규칙)

- **walk-forward**: 2014-01부터 26주마다 재학습하고, 학습에는 *그 시점까지 실제로 관측이 끝난* 라벨만 사용합니다 (`date + h ≤ origin`, purge).
- 피처는 모두 인과적입니다 — 미래 데이터를 잘라내도 각 시점의 피처가 동일함을 테스트로 확인합니다 (`tests/test_engine.py`).
- 거시지표(ECOS)는 발표 시차를 적용한 as-of 결합입니다.
- 기준선: 무변화(RW), 최근 26주 추세 연장(drift), 선형 모멘텀 Ridge. 유의성은 Newey-West Diebold-Mariano.

### 결과 (KB 2026-08-24 파일, 서울 28개 시리즈, 누적수익률 평균 절대오차 %p)

| 기간 | 선형 모멘텀 | 본 엔진 | 오차 감소 |
|---|---|---|---|
| 13주 | 1.20 | 0.92 | −23% |
| 26주 | 2.50 | 2.08 | −17% |
| 52주 | 4.90 | 4.26 | −13% |

- 2014–19 / 2020–21 호황 / 2022–23 하락 / 2024+ **네 국면 모두에서** 선형 모멘텀보다 낫고, 하락 국면에서 격차가 가장 큽니다.
- 이전 버전 앱(서울 지역별 Holt/ARIMA/GBM 앙상블)과 같은 시점(2016~2025 연 1회, 서울 28개 지역)에서 직접 비교하면 평균 오차가 13주 1.12→0.79%p, 26주 2.33→1.44%p 입니다.

### 실험에서 확인된 것 / 안 된 것

- 효과 있음: **전국 패널 풀링**(서울만 학습 대비 큰 개선), **KB 심리지표**(4종 모두 기여, 변화량이 핵심), 상위 권역 대비 상대강도.
- 효과 없음/해로움: 한국은행 ECOS 거시지표(기준금리·국고채·주담대금리·M2·주택가격전망CSI·미분양 등)와 전 지역에 동일하게 붙는 시장 수준 피처 — 시계열 표본이 사실상 하나뿐이라 과적합되어 오히려 성능이 떨어졌습니다. 앱의 *고급(실험)* 옵션으로만 남겨 두었습니다 (`ECOS_API_KEY` 환경변수 또는 `.streamlit/secrets.toml`, 키는 저장소에 넣지 않습니다).
- 예측구간은 급변 국면에서 명목 80%보다 낮게 적중합니다 (검증 탭에 실제 적중률을 표시).

## 한계

- 모델 설계(피처군·정규화 강도)는 같은 과거 구간을 보고 고른 것이므로 위 수치에는 약간의 선택 편향이 있습니다. 다만 결정이 굵직하고 네 국면에서 일관되게 유지됩니다.
- KB 지수는 사후 개정된 최종본입니다 (실시간 빈티지가 아님).
- 정책 충격(대출 규제 등) 이후 국면 전환은 늦게 반영됩니다 — 검증 잔차가 그 시점에 커집니다.
- 투자 권유가 아닙니다.
