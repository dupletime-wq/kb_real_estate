# kb_real_estate

KB 주간시계열(아파트 매매·전세 가격지수) XLSX를 올리면 **전국 197개 지역**의 13·26·52·104주 뒤 가격지수를 예측하는 Streamlit 앱입니다.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py      # 파일을 업로드하면 최초 1회 예측 엔진을 학습·검증합니다 (약 3~4분, 이후 캐시)
pytest                              # 누수·정합성 테스트
python scripts/validate.py 20260824_주간시계열.xlsx   # walk-forward 검증 재현 (서울 금리 보정 전/후 포함; --observed-only: 실제 관측 가격만 사용)
python scripts/forecast_log.py log 20260824_주간시계열.xlsx --hub   # 전향(사전 등록) 예측 기록 → forecast_log/
python scripts/forecast_log.py score 20260824_주간시계열.xlsx --hub # 만기된 기록을 실제 관측값으로 채점
```

| 구성 | 내용 |
|---|---|

| 타깃 | h주 뒤 누적 로그수익률을 직접 예측 (재귀 예측 없음), 앵커 기간 4·8·13·20·26·39·52·78·104주 사이는 보간 |
| 모델 | Ridge(강한 shrinkage) + HistGradientBoosting 평균 블렌드 (78주 이상은 Ridge 단독) |
| 피처 | 39개: 자체 모멘텀(1·2·4·6·8·39주 수익률, 가속), KB 심리지표(수준·변화량·이동평균/3년 평균 이탈), **심리지표의 고점 대비 낙폭**(26·52주 최고점에서 얼마나 내려왔는지), 상위 권역 대비 상대강도. 변동성은 구간 폭 산정에만 사용 (아래 '피처 정리') |
| 서울 보정 | **서울 28개 시리즈에만** 기준금리·CD91(91일) 26주 변화(표준화 평균)에 대한 단일 계수 보정(부호 ≤ 0)을 풀링 예측에 더함 (기본 켬, 사이드바에서 끌 수 있음, 매매지수만) |
| 구간 | walk-forward 잔차 기반 online conformal, 변동성으로 정규화 (목표 90%, 각 원점에 이미 닫힌 잔차만 사용; 실제 적중률은 검증 탭에 그대로 표시), 서울 금리 보정이 적용되는 52주 이하는 보정 후 예측 기준 |

앱은 예측 외에 정보군별 기여도 분해, 지역 순위, 기술지표 신호(기존 기능 유지)를 제공합니다. 매매지수와 전세지수를 같은 엔진으로 예측합니다.

## 최신 주간 자료 자동 보강 (KB 데이터허브)

업로드한 워크북은 스냅샷이라 보통 몇 주 뒤처집니다. KB 데이터허브(data.kbland.kr, 웹페이지가 쓰는 공개 API — 비공식이라 형식이 바뀌면 중단될 수 있음)에서 워크북 이후에 공개된 주간 가격지수(매매·전세)와 심리지표를 붙여 예측 기준일을 앞당깁니다(사이드바에서 끌 수 있음, 실패하면 업로드한 파일만 사용). 모델은 그대로이고 **더 최근 시점에서 시작**할 뿐이며, 2026-08-24 워크북 기준으로 09-21까지 4주가 추가됩니다(서울 매매 108.65 → 109.53, 08-27 금리 인상 반영).

- **값이 정확히 일치할 때만 사용**: 지역 이름·코드는 믿지 않고, 허브의 노드 중 워크북의 겹치는 약 100주를 소수 6자리까지 재현하는 *유일한* 노드만 그 지역으로 인정합니다. 활성 지역의 95% 미만이 매칭되거나 새 주가 없으면 워크북을 그대로 씁니다. 매매·전세 모두 197개 중 192개가 정확히 일치했고(나머지는 이력이 짧은 인천 신설 구·통합 광주/전남), 공개가 끝난 옛 인천 구 3곳과 세종은 새 주가 비어 예측에서 빠집니다.
- **심리지표**: 허브는 반올림(0.1) 값을 줍니다. 허브에 없는 범위 — 서울 강북14·강남11개구, 통합 전 광주/전남, 6개광역시·수도권 등 집계 — 의 새 주는 *서울(또는 전국)의 변화폭을 마지막 워크북 값에 더해 추정*합니다(워크북 과거에서 검증: 4주 뒤 오차 평균 2.5포인트, 마지막 값 유지 시 9.9). 추정된 범위는 화면에 표시됩니다.
- 새로 붙는 주는 검증(walk-forward)에 쓰이지 않습니다. 검증 표는 업로드한 워크북 기간만 다룹니다. 가장 최근 4주는 라이브 예측의 입력일 뿐이라 실현값이 없습니다.
- 월간·주간 심리 원자료도 확인했으나 추가 정보가 없습니다: 월간 심리는 같은 조사의 월 단위 집계이고, 주간 원자료(매수자많음·매도자많음·비슷함 비율)는 이미 쓰는 매수우위지수의 구성요소입니다(예: 75.2 = 100 + 13.7 − 38.5). 새 정보는 가격전망지수뿐이며 아래 실험대로 채택하지 않았습니다.

## 검증 방법 (숫자를 믿기 위한 규칙)

- **walk-forward**: 2014-01부터 26주마다 재학습하고, 학습에는 *그 시점까지 실제로 관측이 끝난* 라벨만 사용합니다 (`date + h ≤ origin`, purge).
- 피처는 모두 인과적입니다 — 미래 데이터를 잘라내도 각 시점의 피처가 동일함을 테스트로 확인합니다 (`tests/test_engine.py`).
- 거시지표(ECOS)는 발표 시차를 적용한 as-of 결합입니다.
- 기준선: 무변화(RW), 최근 26주 추세 연장(drift), 선형 모멘텀 Ridge. 유의성은 Newey-West Diebold-Mariano.

### 결과 (KB 2026-08-24 파일, 서울 28개 시리즈, 누적수익률 평균 절대오차 %p)

| 기간 | 선형 모멘텀 | 본 엔진 | 오차 감소 |
|---|---|---|---|
| 13주 | 1.19 | 0.91 | −24% |
| 26주 | 2.50 | 2.04 | −18% |
| 52주 | 4.89 | 4.14 | −15% |

- 2014–19 / 2020–21 호황 / 2022–23 하락 / 2024+ **네 국면 모두에서** 선형 모멘텀보다 낫고, 하락 국면에서 격차가 가장 큽니다.
- 이전 버전 앱(서울 지역별 Holt/ARIMA/GBM 앙상블)과 같은 시점(2016~2025 연 1회, 서울 28개 지역)에서 직접 비교하면 평균 오차가 13주 1.12→0.79%p, 26주 2.33→1.44%p 입니다.

### 실험에서 확인된 것 / 안 된 것

- 효과 있음: **전국 패널 풀링**(서울만 학습 대비 큰 개선), **KB 심리지표**(4종 모두 기여, 변화량이 핵심), 상위 권역 대비 상대강도.
- 풀링 모델에서 이번 조건에서 채택할 근거가 부족(오차가 같거나 커짐): 한국은행 ECOS 거시지표(기준금리·국고채·주담대금리·M2·주택대출 증가율·주택가격전망CSI·미분양 등)와 전 지역에 동일하게 붙는 시장 수준 피처. 34개를 한꺼번에 넣어도, 이론 기반으로 4~8개만 골라도, 전달 시차를 명시한 피처(금리 충격 누적 반감기 13~104주, 기준금리 변화 0~104주 시차 분포, M2·주택대출 증가율 0~78주 시차)를 넣어도 서울 오차가 같거나 커졌습니다(특히 2020–23년).
- **금리는 "안 통한다"가 아닙니다 → 서울에만 보정으로 반영.** 서울 단독의 단순 선형 모델(모멘텀+KB 심리지표)에 *기준금리 26주 변화*를 추가하면 26·52주 오차 제곱이 약 14% 줄었고(확장창 OLS, p≈0.08), 국고채 3년까지 넣으면 17%였습니다. 개선은 금리 인상 하락기(2022–23)에 집중되어 있습니다. 풀링 모델 위에 부호(−)를 제약한 서울 전용 금리 보정을 얹으면 MAE가 13/26/52주 0.913→0.884, 2.043→1.968, 4.137→3.995%p(−3.2/−3.7/−3.4%, `scripts/validate.py`로 재현) 줄었지만 Diebold-Mariano 유의확률은 단측 p≈0.07/0.06/0.10으로 통계적으로 확정되지 않습니다. 그럼에도 **"서울은 유동성에 더 민감하다"는 경제적 판단에 따라 서울에 한해 기본 적용**했습니다(증거 수준은 '시사적'이지 '입증'이 아닙니다). 197개 지역에 같은 계수를 주는 풀링과 트리 모형이 서울의 금리 민감도를 가렸던 것으로 보입니다. M2·주택대출 증가율은 어떤 방식으로도 도움이 되지 않았습니다.
- **공급 통계(KOSIS 시도별 월별 인허가·착공·준공·분양승인, 시군구별 미분양, 시도별 연간 멸실)와 계절성 피처도 미채택**: 서울 28개 기준 26·52주에서 유의한 개선이 없고 전국 197개에서는 나빠졌습니다(예: 분양승인 52주 4.26→4.53%p, p=0.03 악화, 멸실 52주 4.26→4.49). 착공·분양·인허가의 시군구 단위 월별 자료는 KOSIS에 없어 서울 25개 구는 같은 값을 공유합니다. 이전 실험에서 "인허가가 서울에서 유의하게 도움"이라고 보고한 것은 ECOS의 *연초부터의 누계* 값을 월별 값으로 오해해 만든 피처에서 나온 잘못된 결과이며 정정되었습니다.
- **KB 데이터허브의 PIR·HOI·HAI·가격전망지수도 미채택** (`data-api.kbland.kr`의 공개 조회 API로 수집; 발표시차는 월간은 월말, 분기·HAI는 라벨월 말+2~3개월로 보수적으로 적용). 서울 28개 기준 오차(MAE, %p) 13/26/52주: 기준 0.920/2.081/4.261 → 시도별 매매가격전망지수(월, 2013-04~) 0.908/2.079/4.249, PIR·HOI(분기, 서울·경기·인천만) 0.975/2.185/4.454, HAI(월, 지역군) 0.922/2.107/4.133. 가격전망지수는 13주에서만 서울 오차가 줄었고(제곱오차 기준 p=0.04) 26·52주는 차이가 없으며, 2014–19에서는 좋아지나 2020–21에서 나빠지고 전국 197개에서는 오히려 나빠졌습니다(검정 24개 중 1개가 p<0.05인 수준이라 우연과 구별되지 않습니다). PIR·HOI는 2022–23 금리 인상기에 크게 악화(26주 2.41→2.95)되었습니다. 풀링이 아닌 서울 전용 잔차 보정(확장창, 부호 자유)으로 써도 모든 지표에서 오차가 늘었습니다(MAE +0~12%). PIR은 사실상 KB 자체 매매가격을 소득으로 나눈 값이라 가격 모멘텀과 겹치고, 소득은 연 1회 개정되는 사후 값이라 실시간 정보가 아니라는 한계도 있습니다. 워크북의 매수우위·매매거래활발·전세수급·전세거래활발은 이미 사용 중이므로 다시 넣지 않았습니다.
- **104주(2년) 예측** (이 항목의 기준선은 무변화·추세연장·선형 모멘텀입니다. 과거평균 기준선과 관측값 전용 재측정은 아래 '장기 재검증' 참조): 78·104주 앵커를 추가했습니다(78주 이상은 ridge 단독 — 트리를 섞은 블렌드보다 서울·전국 모두 오차가 작았습니다). 서울 28개 평균오차(%p): 78주 6.13(무변화 10.19, 추세연장 9.84, 선형 모멘텀 7.30), 104주 7.92(무변화 12.80, 추세연장 13.70, 선형 모멘텀 9.40). 104주는 무변화 대비 p=0.002, 추세연장 대비 p=0.04, 선형 모멘텀 대비 p=0.04로 서울에서는 기준선보다 낫지만, **전국 197개는 104주에서 무변화와 거의 같습니다**(8.63 vs 9.31, p=0.31). 독립된 2년 구간이 2014~2024년 5개 안팎뿐이라 사실상 표본이 매우 적고, 예측구간은 넓으며(서울 104주 +5% 예측의 구간이 대략 −9%~+39%) 실제 적중률은 목표 80%보다 낮은 74~77%입니다. 서울 금리 보정은 78·104주에서 개선이 없어(6.13→6.10, 7.92→7.98) 검증 탭에서 보정 전후를 그대로 보여줍니다.
- **LightGBM·랜덤 포레스트 블렌드(미채택)**: ridge+HGB 대비 ridge+LightGBM은 서울 MAE −0.3/+0.0/+0.2%(13/26/52주)로 차이가 없고(scikit-learn의 HistGradientBoosting이 LightGBM 방식의 히스토그램 부스팅이라 성격이 같습니다), ridge+RF는 +1.1/+1.2/+0.8%, 전국 13주에서 p=0.008로 나빠졌으며, HGB+LightGBM+RF 4모델 블렌드도 +0.9/+1.4/+2.2%로 나빠졌습니다. 나무 모델 단독은 ridge보다 서울 26·52주에서 유의하게 나빴고(p 0.02~0.05), 52주에서는 ridge 단독(4.20)이 블렌드(4.21)와 같습니다. 즉 이 문제에서는 표본 대비 신호가 약해 모델 종류를 늘려도 이득이 없습니다.

- 보정 방식: 각 시점에서 *라벨이 이미 확정된* 서울 시리즈의 풀링 모델 잔차를 '기준금리 26주 변화'에 원점 회귀해 계수를 구하고(최소 약 1년치 표본 이후, 양수면 0으로 제한), 그 시점의 금리 변화에 곱해 서울 예측에만 더합니다. 기준금리는 결정 다음 날부터 알려진 것으로 처리합니다(`tests/test_overlay.py`). 금리가 오르는 국면에서는 서울 예측을 낮추고, 내리는 국면에서는 높이는 방향으로 작동합니다. 보정에는 예측 기준일(워크북 마지막 날짜) 시점에 알려진 금리만 쓰므로, 2026-08-24 워크북에는 07-16 인상만 반영되고(26주 변화 +0.25%p) 08-27 인상(현재 기준 +0.50%p)은 다음 워크북부터 반영됩니다.
- 금리 시나리오 시뮬레이션(예측 탭, 서울 한정): 최종 금리와 인상 간격을 가정하면 보정 항이 시간에 따라 어떻게 변하는지 보여줍니다. 보정이 '금리 26주 *변화*'에 비례하므로 같은 속도로 올리는 한 최종 금리(3.5/3.75/4.0%)와 무관하게 최대 하락폭이 같고, 높을수록 하락 압력이 더 오래 지속되며 인상을 멈춘 뒤 26주 후 0으로 돌아갑니다. 금리 *수준*의 누적 효과는 모형에 없고, 다른 요인은 현재 예측 그대로 둔 민감도 분석이며 전체 재예측이 아닙니다. 금리 자료는 저장소의 `kbforecast/data/base_rate.csv`(변경 시점 스냅샷)를 쓰며, ECOS 키를 넣으면 최신 자료로 갱신하고 워크북 마지막 날짜보다 오래된 자료면 경고합니다.
- 예측구간은 목표 90%보다 낮게 적중합니다(52주 서울 약 86%, 104주 약 78%; 위 표). 급변 국면과 긴 호라이즌에서 특히 그렇고, 검증 탭에 실제 적중률·폭·구간점수를 표시합니다.

## 한계

- 모델 설계(피처군·정규화 강도)는 같은 과거 구간을 보고 고른 것이므로 위 수치에는 약간의 선택 편향이 있습니다. 다만 결정이 굵직하고 네 국면에서 일관되게 유지됩니다.
- KB 지수는 사후 개정된 최종본입니다 (실시간 빈티지가 아님).
- 정책 충격(대출 규제 등) 이후 국면 전환은 늦게 반영됩니다 — 검증 잔차가 그 시점에 커집니다.
- 투자 권유가 아닙니다.

## 장기(52·78·104·208주) 재검증 — 관측값 전용 (2026-10)

`python scripts/validate_long.py <워크북> --horizons 52,78,104,208` (결과·예측 원자료·설정은 `validation_runs/long_observed_20260824/`). 조건은 모두 같은 평가 행·같은 재학습 주기(26주)·닫힌 라벨만입니다.

- **관측값 전용**: 원점 가격과 h주 뒤 가격이 모두 실제 관측인 라벨만 모델 학습, 과거평균 기준선, 금리 보정 계수 추정, 구간 보정에 썼습니다. 채운 값으로 학습한 모델을 같은 관측 행에서 채점해도 차이가 0.04%p 이하라(예: 104주 서울 7.95 vs 7.94) 채움 값이 결과를 좌우하지는 않았습니다. 엔진도 기본값이 관측값 전용 라벨입니다.
- **기준선**: 무변화, 풀링 과거평균(전국 닫힌 라벨 평균), 지역 자체 평균을 풀링 평균 쪽으로 50% 수축한 값, 시도(서울은 서울 28개 시리즈) 평균을 50% 수축한 값. 수축 비중 50%는 사전에 고정했고 조정하지 않았습니다. 지역·시도 평균은 모델과 같은 시점에 같은 라벨로 다시 학습한 walk-forward 기준선입니다(엔진/앱의 과거평균 기준선은 매주 갱신되는 확장 평균이라 모델보다 약간 유리하게 잡힙니다).
- 평균오차 MAE(%p). 같은 행에서 비교, 서울 28 = 서울시 + 강북·강남 2개 권역 + 25개 구.

| 호라이즌 | 서울 28 모델 | 풀링 과거평균 | 무변화 | 전국 모델 | 풀링 과거평균 | 무변화 |
|---|---|---|---|---|---|---|
| 52주 | 4.08 | 5.69 | 7.06 | 3.86 | 5.46 | 5.24 |
| 78주 | 6.12 | 7.90 | 10.19 | 6.17 | 7.81 | 7.52 |
| 104주 | 7.94 | 9.66 | 12.78 | 8.60 | 9.58 | 9.30 |
| 208주 | 13.10 | 14.49 | 22.48 | 13.37 | **12.18** | 14.49 |

- **서울 시 지수와 25개 구는 비슷합니다**(MAE 서울시/구: 52주 3.91/4.09, 104주 7.89/7.95). 서울은 모든 호라이즌에서 평균 편향이 음(−, 과소예측)입니다: 서울 28 기준 52주 −1.0, 78주 −2.1, 104주 −2.6, 208주 −9.8%p (전국은 +0.2~+1.2). RMSE는 104주 서울 10.1 vs 풀링 평균 11.8.
- **기간별로 보면 개선이 한 시기에 몰려 있습니다.** 서울 28 52주: 2014–19에는 모델 3.39 vs 풀링 평균 3.40로 차이가 없고, 2020–21(5.58 vs 9.13)·2022–23(4.58 vs 8.12)·2024+(4.19 vs 6.96)에서 벌어집니다. 104주 전국은 2020–21에 모델 13.27 = 풀링 평균 13.27이고 2020년 이후 평가 구간만 보면 모델 10.85가 무변화 10.69보다 낫지 않습니다(서울은 8.9 vs 12.0). 따라서 "52주는 개선이 분명하다"는 표현은 쓰지 않습니다: **서울에서는 이 표본에서 일관되게 과거평균보다 낫지만, 그 차이의 대부분이 2020년 이후의 한 번의 상승·조정 사이클에서 나왔고 선택 편향도 있어 잠정 결과**입니다.
- **중첩 없는 원점**(h주 간격, 가능한 모든 시작 위치의 평균과 범위; 독립 표본 수가 아닙니다): 서울시 지수 MAE 평균(최소–최대) 52주 3.93(2.84–4.75, 원점 약 11개), 104주 7.91(2.22–11.66, 약 5개), 208주 12.44(1.96–30.36, 약 2개). 시작 위치에 따라 결과가 크게 달라질 만큼 표본이 적습니다.
- **지역 평균 기준선은 풀링 평균보다 나쁩니다**(지역·시도 평균 수축: 104주 서울 11.4 vs 풀링 9.7). 짧은 이력의 지역 평균은 그 시기의 사이클을 따라가기 때문입니다.
- **208주는 앱에 넣지 않습니다.** 서울은 풀링 평균보다 −10%이지만 전국은 모델 13.37이 풀링 평균 12.18보다 나쁘고, 중첩 없는 원점이 2개 안팎입니다. 필요한 경우에만 앱의 "4년 가정 시나리오"(직접 정한 연 변화율의 복리 계산, 확률 없음)를 쓰세요.
- **서울 금리 보정**(관측값 전용): 52주 서울 28 4.08→3.93(서울시 3.91→3.77, 90% 구간점수 35.1→33.9)로 유지합니다. 78주는 6.12→6.05로 거의 차이가 없고 104주 7.94→7.99, 208주 13.10→13.44로 도움이 없어 **78주 이상은 기본적으로 끄고**(`engine.OVERLAY_MAX_HORIZON=52`), 이 기간의 구간은 보정 없는 모델 자체의 닫힌 잔차로 계산합니다.
- **104주 ridge + 지역 평균 수축 조합(단일 사전 지정 후보)**: w·ridge + (1−w)·(지역 자체 평균 50% 수축). 비중 w는 2014–2017 원점(라벨이 2019년 말까지 닫히는 내부 구간)에서 서울 28 MAE + 전국 MAE로 고르고(w=1.0: 9.72, 0.75: 9.91, 0.5: 11.49, 0.25: 14.12, 0, 17.03) 2020-01 이후 외부 구간에는 고정했습니다. 선택된 w=1.0, 즉 조합이 곧 현행 ridge이므로 **현행 ridge를 유지합니다**(외부 구간 서울 28 8.91, 지역 평균 12.03).

## 전향 검증과 한계

- 후보 약 20~25개를 같은 워크북으로 시험해 일부(심리 낙폭, CD91 보정, 104주 등)를 채택했으므로 이 수치들은 선택 편향이 있는 "유망 후보"의 과거 성적입니다. 선택과 무관한 증거는 결과가 나오기 전에 기록한 예측뿐입니다: `scripts/forecast_log.py log`를 새 주가 공개될 때마다 실행해 `forecast_log/`에 (원점·지역·호라이즌별 예측, 구간, 기준선, git 커밋, 데이터 지문, 모델 설정 해시)를 남기고, 만기 후 `score`로 실제 관측값 기준 오차를 봅니다. 같은 원점·같은 데이터는 덮어쓰지 않고, 개정된 데이터는 별도 파일로 남습니다.
